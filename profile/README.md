## 功能一览
 
| | |
| :--- | :--- |
| 🗓 **周目** | 按开学日期和周目循环算第几周，圆环按课程进度填充 |
| 📚 **两张课表** | 正课表 / 晚课表互相独立，每天节数可不同，时间可选填 |
| 🏠 **首页两页** | 第一页圆环 + 三行倒计时，第二页当天完整课表 |
| 🏝 **灵动岛** | 上课中 / 课间显示科目与倒计时，上下课前 5 分钟提醒 |
| ⌚️ **Apple Watch** | 随 iPhone 应用一起安装，含四种样式的表盘复杂功能 |
| 🤖 **Android 版** | 同样的周目 / 两张课表 / 首页两页 / 小组件 / 上下课提醒 |
| 🎨 **外观** | 浅色白蓝 / 深色黑蓝 / 跟随系统，图标有深浅两个版本 |
 
## 安装
 
到 **[主仓库的 Release](https://github.com/zhoumu-app/zhoumu/releases/latest)** 下载无签名 IPA，
用 Sideloadly / AltStore / ESign 等工具自签安装。
 
> 一个 IPA 同时包含 iPhone 应用、小组件、手表应用和表盘复杂功能。
> 自签时**四个部分都要重签**，否则对应的功能会失效。
